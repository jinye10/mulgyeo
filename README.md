# 🌊 물결 (Mulgyeol)

> 드릴 단위 훈련 기록과 전후 영상 비교 리포트로, 수영학원 학부모에게 아이의 성장을 보여주고 강사의 피드백 전화 부담을 줄이는 서비스

**AI데이터기반서비스기획 · MVP**

---

## 📌 문제 정의

| 대상 | 겪는 문제 |
|---|---|
| **학부모** | 월 20~40만 원 강습비를 내지만 아이가 무엇이 나아졌는지 확인할 방법이 없음 (통창·CCTV는 그 순간만 보여 줌) |
| **강사** | 수십 명의 진도를 기억·수기로 관리, 매일 18~25명에게 피드백 전화 → 하루 30분~1시간 무급 연장 근무 |

**원인:** 시설이 아니라 **기록의 방식**. 훈련이 드릴 단위로 기록되지 않아 지난달과 비교할 수 없음

## 💡 해결 방법

- 강사는 수업 후 **드릴마다 완료 · 진행 · 미실시를 탭**으로 기록 (지난 기록이 미리 선택되어 바뀐 것만 누름)
- 물결이 **진행률을 계산하고 지난달과 비교한 리포트를 자동 생성**
- 학부모는 **가입 없이 링크 하나로** 진행률 · 전후 영상 · 강사 코멘트 확인

## 🎯 MVP 성공 기준

| 기준 | 목표 | 측정 방법 |
|---|---|---|
| 학부모 체감도 | "이전 방식보다 성과가 더 잘 보인다" **70% 이상** | 리포트 하단 설문 |
| 강사 부담 | 피드백 전화 준비·통화 시간 **절반 이하** | 회원별 입력 시간 자동 기록 |

- 시범 운영: 2027년 1~2월 중 4주 · 강사 1~2명 · 학부모 10~15명

## 🖥️ 화면 구성

| 번호 | 화면 | 파일 | 사용자 |
|---|---|---|---|
| S1 | 소개페이지 | `index.html` | 누구나 |
| S2 | 강사 회원가입 | `signup.html` | 강사 |
| S3 | 로그인 | `login.html` | 강사 |
| S4 | 강사 대시보드 (오늘 수업 · MVP 성공 기준 · 회원 현황 · 반/회원 관리) | `teacher.html` | 강사 |
| S5 | 드릴 체크 입력 | `check.html` | 강사 |
| S6 | 학부모 성장 리포트 (로그인 없이 링크로 열람) | `report.html` | 학부모 |

### 서비스 흐름

```
강사: 오늘 수업 반 선택 → 회원별 드릴 체크 + 코멘트 + 영상(선택)
  ↓
물결: 진행률 계산 · 지난달과 비교 · 리포트 자동 생성
  ↓
학부모: 카카오톡으로 받은 링크로 리포트 확인 → 체감도 설문 응답
```

### 주요 기능

- **강사 웹 대시보드**: 오늘 기록 현황, 학부모 체감도(목표선 표시), 평균 입력 시간, 회원별 진행률
- **드릴 체크**: 회원 이름을 눌러 바로 이동, 기록한 회원은 ✓ 표시, 입력 시간 자동 측정
- **학부모 리포트**: 진행률과 지난달 대비 변화, 전후 영상 나란히 보기, 완료·연습 중 드릴, 강사 한마디
- **뒤로 가기**: 모든 화면에서 바로 전 화면으로 이동
- **체험 모드**: Supabase 연결 전에도 예시 데이터(반 3개, 회원 9명)로 모든 화면 동작
- **반응형 · 다크 모드**: PC 대시보드, 휴대폰 화면 모두 지원

## 🚀 실행 방법

### 바로 둘러보기 (체험 모드)

GitHub Pages 를 켜면 바로 예시 데이터로 모든 화면을 둘러볼 수 있어요.

1. 저장소 **Settings → Pages**
2. Source: **Deploy from a branch** / Branch: **main**, **(root)** → **Save**
3. 1~2분 뒤 `https://jinye10.github.io/mulgyeo/` 접속

### 실제 데이터로 쓰기 (Supabase 연결)

**1. Supabase 프로젝트 만들기**
- https://supabase.com 가입 → **New project** (Region: Northeast Asia (Seoul))
- **SQL Editor** 에 `supabase/schema.sql` 전체를 붙여넣고 **Run** (한 번만)

**2. `config.js` 수정**
- Supabase **Project Settings → API** 의 Project URL 과 anon public 키를 붙여넣기

```js
window.MULGYEOL = {
  SUPABASE_URL: "https://abcdefgh.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi...",
};
```

> anon 키는 공개되어도 괜찮은 키예요. **service_role 키는 절대 넣지 마세요.**

**3. Supabase 에 내 주소 등록**
- **Authentication → URL Configuration**
  - Site URL: `https://jinye10.github.io/mulgyeo/`
  - Redirect URLs: `https://jinye10.github.io/mulgyeo/**`
- (선택) 시범 기간엔 **Authentication → Sign In / Providers → Email** 에서 Confirm email 끄기

**4. 사용 순서**
1. 강사 회원가입 → 로그인
2. 반·회원 관리에서 반 만들기 → 회원 추가
3. 수업 후 **오늘 수업 기록하기** → 드릴 체크 → 저장
4. 회원 현황에서 **링크 복사** → 카카오톡으로 학부모에게 전송

### 시범 운영 결과 확인

Supabase **Table Editor** 에서 CSV 로 내려받아 집계

| 확인할 것 | 테이블 → 칸 |
|---|---|
| 학부모 체감도 | `surveys` → `answer` (yes / same / no) |
| 강사 입력 시간 | `sessions` → `input_seconds` |
| 드릴별 기록 | `records` |

## 🔒 개인정보 · 주의사항

- 아이 영상은 **보호자 동의를 받은 경우에만** 업로드 (만 14세 미만은 법정대리인 동의 필요)
- 리포트와 영상은 **링크를 가진 사람만** 열람 가능. 해당 학부모에게만 전송
- 아이 영상·개인정보는 **GitHub 에 올리지 않음**. 모든 데이터는 Supabase 에 저장
- 강사는 자기 반 회원만 조회·수정 가능 (데이터베이스 보안 규칙)
